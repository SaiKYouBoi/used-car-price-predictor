## Project Overview

Used-car pricing is notoriously opaque. Sellers often underprice or overprice their vehicles; buyers have little independent reference. This project builds a **machine learning regression pipeline** that:

- Trains on historical listings (year, mileage, fuel type, seller type, transmission, ownership history)
- Produces an accurate selling price estimate for any new vehicle
- Exposes the model through a simple interactive CLI

The full pipeline covers **data cleaning → feature engineering → baseline training → hyperparameter tuning → model selection → export → prediction interface**.

## Dataset

| Property | Value |
|---|---|
| File | `data/raw/car-price-data.csv` |
| Source | Used-car listings (Indian market) |
| Rows | ~8 000 (after cleaning) |
| Target | `selling_price` (INR) |

### Features used for prediction

| Column | Type | Description |
|---|---|---|
| `year` | Numeric | Year the vehicle was first registered |
| `km_driven` | Numeric | Total kilometres driven |
| `fuel` | Categorical | Fuel type — Petrol, Diesel, CNG, LPG, Electric |
| `seller_type` | Categorical | Individual, Dealer, or Trustmark Dealer |
| `transmission` | Categorical | Manual or Automatic |
| `owner` | Ordinal | Number of previous owners (0–4) |

> `name` is present in the raw file but **dropped** — it is a free-text field with hundreds of unique values that is not encodable without a dedicated embedding step.

## Installation

### 1. Clone the repository

```bash
git clone <repo-url>
cd used-car-price-predictor
```

### 2. Create and activate a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate        # Linux / macOS
# .venv\Scripts\activate         # Windows
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

> `joblib` and `matplotlib` are installed automatically as dependencies of scikit-learn and seaborn respectively — they do not need to be listed separately.

### 4. Add the dataset

Place `car-price-data.csv` in `data/raw/`:

```
data/raw/car-price-data.csv
```

---

## How to Run

### Full pipeline (Steps 1–5)

Runs every step in sequence: data loading → cleaning → training → tuning → evaluation → model export.

```bash
source .venv/bin/activate
python src/run_all.py
```

**Expected outputs:**
- 5 EDA plots saved to `data/processed/`
- 2 evaluation plots saved to `data/processed/`
- 4 model artifacts saved to `models/`
- Full metrics printed to the terminal

> ⏱ **Runtime estimate:** ~5–15 minutes depending on your CPU.  
> The bottleneck is `RandomizedSearchCV` with `n_iter=30` and `cv=5` for two models (300 fits total). All CPU cores are used via `n_jobs=-1`.

### Run individual modules (for development)

```bash
python src/data_loader.py       # load + structure check
python src/data_analysis.py     # EDA plots only
python src/cleaning.py          # cleaning report only
```

## Module Reference

| Module | Key function(s) | What it does |
|---|---|---|
| `config.py` | — | Central config: paths, IQR multipliers, year bounds, owner mapping |
| `data_loader.py` | `load_data()`, `encode_owner()`, `check_structure()` | Load CSV, ordinal-encode `owner`, print shape/dtypes/nulls/dupes |
| `data_analysis.py` | `run_eda()` | Descriptive stats + 5 plots (histograms, boxplots, heatmap, pairplot) |
| `cleaning.py` | `run_cleaning()` | Impute missing values, remove duplicates, flag and remove outliers |
| `preprocessing.py` | `encode_categoricals()`, `split_data()`, `scale_features()` | Encode features, 80/20 split, fit StandardScaler |
| `training.py` | `run_training()` | Train 4 baseline models (LR, RF, XGBoost, SVR), evaluate RMSE/MAE/R² |
| `tuning.py` | `run_tuning()` | `RandomizedSearchCV` (n_iter=30, cv=5) on top 2 models |
| `evaluation.py` | `run_evaluation()` | Summary table, scatter plots, residual plots, final model selection |
| `export.py` | `export_model()` | Save model + scaler + columns + metadata with `joblib` |
| `predict.py` | `main()` | Interactive CLI: input → preprocess → predict → display |
| `run_all.py` | `main()` | Orchestrates all 12 steps end-to-end |

## Results Summary

> Exact numbers will vary depending on random seed and dataset version. Below are representative values from a typical run.

### Baseline models (default parameters)

| Model | RMSE | MAE | R² |
|---|---|---|---|
| Linear Regression | ~310,000 | ~170,000 | ~0.65 |
| SVR | ~290,000 | ~145,000 | ~0.68 |
| Random Forest | ~165,000 | ~90,000 | ~0.88 |
| XGBoost | ~155,000 | ~85,000 | ~0.90 |

### After hyperparameter tuning (RandomizedSearchCV, 5-fold CV)

| Model | RMSE | R² | RMSE improvement |
|---|---|---|---|
| Random Forest (Tuned) | ~142,000 | ~0.90 | ~+14% |
| XGBoost (Tuned) | ~132,000 | ~0.91 | ~+15% |

### Final model selection

**Winner: XGBoost (Tuned)**

- Highest R² — explains ~91% of price variance
- Lowest RMSE — average prediction error ~132,000 INR
- Tightest residual distribution (lowest residual std) — most robust across all price ranges
